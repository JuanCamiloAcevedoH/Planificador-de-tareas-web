# 📋 Planificador de Tareas - Sprint 1

Aplicación web interactiva desarrollada para la gestión y organización de tareas cotidianas. Proyecto construido con un enfoque responsivo y arquitectura modular en el marco del programa Generation Colombia.

## 🚀 Tecnologías Utilizadas

* **HTML5:** Estructuración semántica de la interfaz.
* **CSS3:** Variables globales de color, tema oscuro (Dark Slate Pro) y personalizaciones de alto contraste.
* **Bootstrap 5 & Icons:** Sistema de rejilla responsivo, componentes de tarjeta y modales interactivos.
* **JavaScript (ES6):** Manipulación del DOM, manejo de eventos y validación de datos.

## ⚙️ Funcionalidades Implementadas (Sprint 1)

1. **Maquetación Responsiva:** Adaptable a pantallas de escritorio, tablets y dispositivos móviles.
2. **Interfaz de Alto Contraste:** Tema oscuro moderno diseñado con variables CSS personalizadas.
3. **Mapeo Visual de Tareas:** Muestra de tarjetas clasificadas por código de color según su estado (*Pendiente*, *En proceso*, *Completada*).
4. **Validación Interactiva de Datos:** Control de errores mediante JavaScript que impide el registro de campos vacíos y notifica al usuario mediante modales emergentes de Bootstrap.
